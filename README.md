# WorkoutLevelling

Fitness tracker app thing

Features:
. A list of common muscles and muscle groups targeted during physical fitness, they will be used to catergorise exercises.
. A list of exercises the user may choose from to add to their log - the exercises can each list name, a list of muscle groups targeted, and later a thumbnail and instructional video.
. The ability for the user to create custom exercises for personal use if deemed necessary, and later the ability to share the exercise  
. Individual exercise logging for workout sessions detailing the exercise, reps done per set, if it's a bodyweight exercise, weight lifted, and some additional info like rest period taken before exercise,
